# Карта: Туркестанская область — ОВН и АПК ЛУ

Интерактивная карта (Leaflet): 643 объекта, фильтры по типу, статусу и району, поиск, редактирование.

- `index.html` — карта
- `data.geojson` — данные (карта читает их при загрузке; это файл, который обновляет кнопка «Сохранить на GitHub»)

## Редактирование
Кнопка «Режим редактирования»: тяните точки, меняйте статус и координаты в карточке точки.
Правки сохраняются в браузере; чтобы они появились у всех, нажмите «Сохранить на GitHub» (нужен fine-grained токен с правом Contents: Read and write на этот репозиторий).
Также можно скачать данные в GeoJSON / CSV / KML.
